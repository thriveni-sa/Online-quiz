# 🧠 Online Quiz App

An interactive and user-friendly web application that allows users to select their preferred subject, answer multiple-choice questions, and test their knowledge in an engaging way.

## ✨ Features

- 🏠 **Welcome Page** – A simple interface to start the quiz.
- 📚 **Subject Selection** – Choose a preferred subject to play.
- ❓ **Multiple-Choice Questions** – Answer questions with different options.
- ⏱️ **Countdown Timer** – Answer questions within the allotted time.
- 📊 **Progress Tracking** – Track progress throughout the quiz.
- 🏆 **Automatic Scoring** – Calculate the score based on correct answers.
- 📈 **Results Page** – View the final score and performance.
- 🔄 **Play Again** – Restart the quiz and choose another subject.

## 🛠️ Technologies Used

- **HTML5** – Structures the web application.
- **CSS3** – Styles the interface and improves the visual experience.
- **JavaScript** – Handles quiz logic, timers, scoring, and user interactions.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in your code editor.
3. Open `index.html` in your web browser.

## 🎮 How to Play

1. Open the application.
2. Click the **Start Quiz** button.
3. Select your preferred subject.
4. Answer the multiple-choice questions.
5. Complete the quiz within the given time.
6. View your final score and performance.
7. Play again or choose another subject.

The main objective of this project is to make learning more interactive and enjoyable by providing students with a platform to test their knowledge across different subjects.
